            What this view can’t see

            Every connection is logged by host, allowed or blocked. Programs are sampled a few times a second, so one that starts and exits in between is missed, and their arguments are never logged. File access the sandbox refuses is logged, but successful file reads are not: tracing them needs root. File changes can include edits made outside the sandbox, and tool events are reported by the agent itself.
